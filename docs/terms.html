Current downloads are not signed with an Apple Developer ID. macOS Gatekeeper may block a double-click. Drag Pulse.app to Applications, then run xattr -cr /Applications/Pulse.app in Terminal, then open Pulse. The first check that reads a Keychain item will ask Pulse to use the keychain — choose Always Allow.
